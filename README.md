# The Age of Time

Учебный игровой проект — небольшая **3D-игра**, разработанная на игровом движке **Unity** в рамках университетского курса по разработке игр.

Проект был создан для изучения базовых принципов разработки игр, работы с игровым движком Unity и реализации игровой логики на языке **C#**.

## О проекте

The Age of Time — это небольшой игровой прототип, в котором реализованы основные механики взаимодействия игрока с игровым миром.

Проект создавался в учебных целях и позволил познакомиться со структурой игровых проектов на Unity, управлением игровыми объектами, обработкой пользовательского ввода и построением игровой логики.

В рамках разработки были реализованы базовые элементы игрового процесса, включая управление персонажем, взаимодействие с объектами сцены и организацию игровой среды.

## Стек технологий

- Unity
- C#
- Unity Engine
- Visual Studio

## Реализованные элементы

- управление персонажем
- перемещение по игровой сцене
- обработка пользовательского ввода
- взаимодействие игровых объектов
- организация игровых сцен
- скриптовая логика на C#

## Структура проекта

```text
The_age_of_time/
```
